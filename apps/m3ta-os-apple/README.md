# BAMA M3ta-OS — Apple platforms
`BAMA.xcodeproj` is generated by `scripts/gen_xcodeproj.py`. Re-run the script after adding targets. It uses synchronized folders, so new files are picked up automatically.
Targets: BAMA (iPhone + iPad, adaptive sidebar), BAMAWidgets (widgets + Live Activity), BAMAWatch (standalone watchOS app),
BAMAWatchWidgets (complications), BAMAMac (signed-app wrapper of ../m3ta-os-console), BAMATests. Shared logic lives in the ConsoleCore SwiftPM library.
Signing: Config/Signing.xcconfig (team J299Y77V8C, automatic). Simulator build: add `CODE_SIGNING_ALLOWED=NO`.
